# Firewall Simulation Using Python

Simple firewall simulation script that randomly generates local IP addresses and checks them against a set of blocking rules.

Files
- `Python-passgen.py` — main script that generates IPs and prints whether they are blocked or allowed.

How to run (Windows PowerShell)

1. (Optional) create a virtual environment and activate it:

   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

2. Run the script:

   python "Python-passgen.py"

Notes
- This is a small demo script intended for learning and demonstration only.
